## 🏛️ Descripción del Proyecto

**LEX & AI LEGAL LAB** es una landing page de alta gama institucional, estética sobria y moderna (*Midnight Blue & Muted Gold*) con acabado **Glassmorphism**, orientada al debate dogmático-jurídico sobre la imputación de responsabilidad, explicabilidad algorítmica y protección de derechos fundamentales frente al despliegue de sistemas de IA y modelos generativos.

---

## ✨ Características Principales

- **Sistema de Pestañas Dinámicas (Tabs):**
  - **Pestaña 1: Visión & Riesgo Jurídico:** Premisa dogmática y 3 ejes jurídicos (*Ética y Trazabilidad*, *Dignidad Humanizadora vs. Reduccionismo*, y *Cuidado y Relacionalidad*).
  - **Pestaña 2: Análisis Académico (Ponencias Sala 1):** 4 ponencias con lectura dogmática estructurada (Bioética, Derecho Probatorio, Remuneraciones y Salud Mental).
  - **Pestaña 3: Recursos Multimedia:** Reproductor de video de alta definición integrado (iframe YouTube) y botón con enlace a repositorio audiovisual externo.
- **Formulario de Captación de Datos (Lead Generation):** Con validación de campos, selección de área jurídica especializada y confirmación interactiva.
- **Diseño 100% Responsive:** Adaptado para móviles, tabletas y monitores de alta resolución.
- **Efectos Parallax y Microinteracciones:** Orbes atmosféricos con reacción al cursor y botones con efectos resplandecientes en oro mate (*Muted Gold*).

## 🚀 Despliegue Rápido en GitHub Pages (Gratuito)

Este proyecto está 100% preparado para ser publicado gratis en la web mediante **GitHub Pages**:

1. Sube este repositorio a tu cuenta de GitHub (ver sección de comandos abajo).
2. En GitHub, ve a **Settings** > **Pages**.
3. En **Source**, selecciona `Deploy from a branch`.
4. Elige la rama `main` y la carpeta `/ (root)`.
5. Haz clic en **Save**. En 1 o 2 minutos tu sitio estará en línea en:  
   `https://<tu-usuario>.github.io/<nombre-del-repositorio>/`

---

## 💻 Ejecución Local

No requiere NodeJS ni instalación de dependencias pesadas:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/<tu-usuario>/lex-ai-legal-lab.git
   cd lex-ai-legal-lab
   ```
2. Abre `index.html` en tu navegador favorito haciendo doble clic, o ejecuta un servidor ligero:
   ```bash
   # Con Python 3
   python3 -m http.server 8000
   ```
3. Visita `http://localhost:8000` en tu navegador.
